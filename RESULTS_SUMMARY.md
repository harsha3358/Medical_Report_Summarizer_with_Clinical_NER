# Results Summary — Medical Report Summarizer with Clinical NER

## Objective 1: Medical Text Summarization

### Model Comparison on CNN/DailyMail (test[:500])

| Model | Architecture | ROUGE-1 (F1) | ROUGE-2 (F1) | ROUGE-L (F1) | Notes |
|-------|-------------|:------------:|:------------:|:------------:|-------|
| LSTM (No Attention) | Seq2Seq LSTM, 2-layer, hidden=512 | ~0.072 | ~0.031 | ~0.082 | Trained on train[:5000], 2 epochs |
| LSTM + Attention | Seq2Seq LSTM + Dot-Product Attention | ~0.085 | ~0.038 | ~0.095 | Same data, teacher forcing p=0.5 |
| Flan-T5-Large | Encoder-Decoder Transformer (780M params) | ~0.380 | ~0.170 | ~0.350 | Prompt-based, no fine-tuning |
| BART-Large-CNN | Denoising Autoencoder Transformer | ~0.440 | ~0.210 | ~0.410 | Fine-tuned on CNN/DailyMail |

> **Best Model:** BART-Large-CNN achieves the highest ROUGE scores across all metrics.  
> **Ablation:** LSTM + Attention outperforms vanilla LSTM by ~15% relative ROUGE-L, confirming attention's value.

## Objective 2: Clinical Named Entity Recognition (NER)

### Entity Extraction — dslim/bert-base-NER + Clinical Domain Vocabulary

| Entity Type | Examples Extracted | Approach |
|-------------|-------------------|----------|
| Disease | diabetes, cancer, pneumonia, hypertension | BERT NER (MISC) + clinical keyword matching |
| Drug | insulin, aspirin, metformin, amoxicillin | BERT NER (MISC) + clinical keyword matching |
| Symptom | fever, pain, cough, fatigue, breathlessness | Clinical keyword matching on summary |
| Treatment | surgery, chemotherapy, dialysis, radiation | Clinical keyword matching on summary |

**Pipeline Flow:**
```
Input Text → Text Cleaning → Flan-T5-Large Summarization
  → dslim/bert-base-NER (Pass 1: context-aware)
  → Clinical Vocabulary Matching (Pass 2: domain enrichment)
  → JSON Output
```

**API Response Format:**
```json
{
  "lstm_summary": "The patient presents with...",
  "bart_summary": "Patient diagnosed with diabetes showing fever and fatigue treated with insulin.",
  "entities": {
    "disease":   ["diabetes"],
    "drug":      ["insulin"],
    "symptom":   ["fever", "fatigue"],
    "treatment": ["dialysis"]
  }
}
```
